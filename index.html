頁面工作區

加入一個或多個 PDF（多個檔案 = 合併）。每一頁會變成一張卡：drag 上 drag 落重排、㩒卡片選取、逐頁旋轉、刪除或者只保留所選，最後輸出一個結果 PDF。有 restricted / protected 嘅 PDF 都照樣處理到。

拖放 PDF 檔案到呢度
或者㩒一下揀檔案（可以一次揀多個）
    工作區暫時未有頁面。加入 PDF 之後，每一頁就會好似一張紙咁擺喺呢張枱上面。

                      掃描件認字（OCR）

                      如果份 PDF 係掃描出嚟嘅相（揀唔到字、搵唔到字），「PDF ⇄ Word」嗰個 tab 會攞到零個字。 呢度就係補呢個窿：逐頁認返啲字出嚟，再出 DOCX／TXT／Markdown。 認字引擎只會喺你㩒入呢個 tab 嗰陣先下載，唔會拖慢其他功能。

                        設定

                        由細至大，愈大愈準但下載愈多、行得愈慢。公司機用 tiny，屋企部 5090 可以試 medium。

                        課本每行漢字上面嗰啲 xiě gěi 就係拼音。PaddleOCR 會將佢哋分開成獨立區塊，所以可以乾淨咁隔走。

                        每個區塊都有信心分數。實測顯示認錯嘅位置分數明顯偏低，調高門檻可以濾走大部分錯字（代價係會漏咗一啲字）。

                          用邊個模式？

                          ① 繁體字型

                          原 PDF 嵌入嘅係簡體字型嘅子集，入面根本冇繁體字形，所以轉咗嘅字一定要用另一隻字型畫。

                          想更似原文字體（宋配明體、楷配楷體），可以自己上載，再逐隻指定：

                          拖放字型檔到呢度
                          支援 TTF / OTF（可多選）
                            建議用 TTF。fontkit 對 OTF（CFF 輪廓）嘅子集化有 bug 修唔到，只可以完整嵌入，出嚟嘅檔案會大好多（例如 +5MB）。TTF 經修正後可以正常子集化，通常只加幾百 KB。

                            ② 轉換選項

                            同一個簡體字，香港同台灣可以寫法唔同。例如簡體「里」（裏面嘅意思）：
                            　🇭🇰 香港寫「裏」　　🇹🇼 台灣寫「裡」

                            OpenCC 原樣係唔經任何地區調整嘅原始轉換表。佢會用返一啲舊寫法，例如「为」會變「爲」而唔係「為」、「里」會變「裏」。 呢個係俾學術用途或者想自己控制嘅人用；日常文件請揀香港或台灣。

                            喺香港用 → 揀香港。俾台灣客／同事睇 → 揀台灣。唔肯定 → 揀香港。
                            只換需要改嘅字＝最大程度保留原檔（未改嘅字連 byte 都一樣），但同一行會出現兩種字體。統一字型＝連唔使改嘅漢字都用新字型重繪，成頁字體一致、睇落乾淨，代價係原本嘅楷體／宋體美術效果會冇咗（拼音、數字、英文一律唔郁）。想兩樣都要嘅話，就上載對應款式嘅字型（楷配楷、宋配明），再喺下面逐隻指定。
                            內建已經有 OpenCC 嘅 9,726 條詞組，呢度淨係用嚟補漏或者改港式用詞。前後字數要一樣。
                            ⚠️ 呢格預設係空嘅，唔好亂填。喺呢度寫嘅規則會全份文件一刀切，唔理上下文。

                            例如你寫 发=髮，就連「发生」都會變成「髮生」；寫 干=乾，「干部」就會變「乾部」、「若干」變「若乾」。

                            一個簡體字對多個繁體字（发→發/髮、干→乾/幹/干、里→裡/裏）本身要睇上下文，內建詞庫已經處理咗絕大部分。 正確用法係：先轉換，喺下面嘅分析報告見到邊個字真係轉錯，先㩒一下加落嚟改。

                            ③ 分析報告

                            「樣本」欄係由你份 PDF 度直接擷取嘅原圖，睇一眼就知邊隻係楷、邊隻係宋、邊隻係黑。字型檔名帶住 Kai／Serif／Sans／楷／宋／黑 呢類字眼嘅話，㩒「自動配對」就會自己填。
